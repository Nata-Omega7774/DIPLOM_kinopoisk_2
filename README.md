# DIPLOM: Автоматизация тестирования сайта Кинопоиск

## Описание проекта
Проект по автоматизации тестирования UI и API для сайта Кинопоиск. 
Включает набор автотестов для проверки функциональности поиска фильмов.

## Технологии
- Python 3.11
- Selenium 4.15.2
- Requests 2.31.0
- Pytest 7.4.4
- Allure Framework 2.13.2
